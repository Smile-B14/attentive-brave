ATTENTIVE BRAVE TEST LAUNCHER

Requirements:
- Windows 10 or 11
- Brave Browser already installed

Use:
1. Keep the windows-launcher and standalone-extension folders together.
2. Double-click Start-Attentive-Brave.cmd.
3. The launcher opens Brave with a separate profile under:
   %LOCALAPPDATA%\Attentive Brave\User Data

This package is an immediate test launcher, not a compiled custom Brave
installer. The full source integration is in the repository and needs a
complete Windows Brave/Chromium build.

If Brave blocks the command-line extension, open brave://extensions, enable
Developer mode, choose Load unpacked, and select the standalone-extension
folder.
